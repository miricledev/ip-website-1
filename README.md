# Inner Performance Website

A luxurious, high-tech, multi-page static website for Inner Performance - a mental training and behaviour coaching organisation.

## 🎯 Features

- **Luxury Design System**: Dark royal blue (#0b2350) with shiny gold accents and white trims
- **Multi-page Structure**: 7 comprehensive pages covering all services
- **Responsive Design**: Mobile-first approach with smooth animations
- **Video Background**: Hero section with professional video background
- **Interactive Elements**: Scroll animations, parallax effects, and micro-interactions
- **WhatsApp Integration**: Direct messaging integration for instant contact
- **Form Handling**: Client-side validation with AJAX submission simulation
- **Gallery System**: Lightbox modal with random photo selection
- **SEO Optimised**: Meta tags, structured data, and semantic HTML

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Local web server (optional, for testing)

### Installation
1. Clone or download the project files
2. Replace placeholder assets with actual content:
   - `assets/hero.mp4` - Your hero background video
   - `assets/hero.webm` - WebM version of hero video
   - `assets/youth-brochure.pdf` - Your actual youth program brochure
3. Update contact information in all HTML files:
   - Phone: `+44 7719504107`
   - Email: `innerpk@tutanota.com`
   - WhatsApp links are pre-configured

### Running the Website
1. **Local Development**: Open `index.html` in your browser
2. **Web Server**: Upload all files to your web server
3. **Static Hosting**: Compatible with GitHub Pages, Netlify, Vercel, etc.
